SQLite FTS5 & Trigger WAL Reference

Quick reference for external-content FTS5 tables, column-scoped update triggers, and volume-backed snapshots.

Core SQLite Storage Primitives

External-Content FTS5 Table

Prevents FTS5 from duplicating text inside a shadow _content table by pointing directly at the parent relational table.

USING fts5(..., content='deals', content_rowid='id')
External-Content Delete Command

External-content FTS5 tables require inserting the special 'delete' command with old column values rather than running DELETE FROM.

INSERT INTO deals_fts(deals_fts, rowid, ...) VALUES ('delete', old.id, ...)
Column-Scoped Update Triggers

Restricts AFTER UPDATE triggers so mutating unindexed columns (e.g. description, temperature) never fires FTS index churn.

AFTER UPDATE OF title, clean_text, merchant ON deals
Trigger Drop Before Bulk Mutation

In migrations that both bulk-update rows and rebuild FTS indexes, drop existing triggers first to avoid row-by-row trigger WAL amplification.

DROP TRIGGER deals_au; UPDATE deals SET ...;
Single-Pass FTS Rebuild

Populates an external-content FTS5 index in one bulk pass from its parent table after creating the virtual table.

INSERT INTO deals_fts(deals_fts) VALUES('rebuild');
Persistent-Volume VACUUM INTO

Write hot SQLite snapshots to the persistent volume directory (/data) rather than container /tmp (which may be RAM-backed tmpfs).

Path.dirname(System.get_env("DATABASE_PATH"))

SQLite Storage & Migration Audit Checklist

  • [ ] No Redundant Raw HTML: Are raw HTML fields discarded once normalized text and metadata are extracted at ingestion?
  • [ ] External Content FTS5: Does every FTS5 virtual table specify content='...' to avoid shadow table duplication?
  • [ ] Scoped Triggers: Do all AFTER UPDATE triggers specify OF col1, col2 instead of firing on every column update?
  • [ ] Trigger Ordering: Do migrations drop triggers before executing bulk UPDATE or DELETE statements?
  • [ ] Snapshot Volume: Does VACUUM INTO write to a persistent disk mount rather than /tmp?
