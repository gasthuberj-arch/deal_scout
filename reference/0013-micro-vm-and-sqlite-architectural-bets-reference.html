Core Architectural Invariants

Multiplicative Pool Memory

Pager cache multiplies across pool connections: $N_{\text{conn}} \times |\text{cache\_size}|$. Default -64000 KiB × 5 = 312.5 MiB. Tune cache_size to -8000 KiB (8 MiB/conn = 40 MiB total) to prevent cgroups OOM.

cache_size: -8000, # 8 MiB per conn pool_size: 5 # 40 MiB total max cache
Immediate Write Intent

DEFERRED transactions start with no lock, acquire SHARED on SELECT, and deadlock when upgrading to RESERVED if another connection reads. IMMEDIATE acquires RESERVED immediately, serializing writers in busy_timeout.

default_transaction_mode: :immediate, busy_timeout: 5000 # 5s queueing tolerance
Process Boundary Signal Contract

Container orchestrators default to SIGINT. Erlang/OTP releases hook SIGINT to interactive break prompts, stalling until SIGKILL. Explicitly map kill_signal to SIGTERM so init:stop drains sockets and commits WAL checkpoints.

# fly.toml kill_signal = "SIGTERM" kill_timeout = "15s"
Volume Pinning & Proxy Limits

Single NVMe block volumes cannot autoscale horizontally across multiple nodes. Admission control limits must match single-node physical capacity, and deploys must use immediate replacement strategy.

[deploy] strategy = "immediate" [http_service.concurrency] soft_limit = 200, hard_limit = 300
BEAM Memory Allocators in cgroups v2

ERTS allocators retain memory carriers by default. Under strict 512 MB cgroups limits, configure Address Order Best Fit (aobf) and 0% carrier utilization (acul 0) so unused memory returns to the Linux kernel immediately.

RELEASE_VM_ARGS="-MBas aobf -MBacul 0 \ -MBsmbcs 64 -MBlmbcs 128"
Continuous WAL Streaming (Litestream)

Avoid in-memory snapshots (`VACUUM INTO /tmp`) which balloon RAM in micro-VMs. Run Litestream as a sidecar process to stream WAL frames to S3/Tigris every 1s with sub-second RPO and automatic disaster recovery on boot.

litestream replicate /data/deal_scout.db \ s3://my-bucket/deal_scout.db

Transaction Mode Decision Matrix

Mode Initial Lock Upgrade Behavior Concurrency Safety
DEFERRED None (acquires SHARED on first SELECT) Attempts upgrade to RESERVED on first write High Deadlock Risk: Concurrent read-then-write deadlocks and throws SQLITE_BUSY.
IMMEDIATE RESERVED immediately on BEGIN None required; lock held from start Safe: Other readers continue; competing writers wait politely in busy_timeout.
EXCLUSIVE EXCLUSIVE immediately on BEGIN Blocks all other readers and writers Heavy; rarely needed outside of maintenance or exclusive migrations.
