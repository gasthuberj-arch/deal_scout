Distributed Resilience & Rate-Limiting

Quick reference for ingestion resilience, backoff rules, jitter, and memory reclamation.

Core Resilience Architecture Primitives

Ephemeral Task Isolation

Spawn parsing and network tasks under a Task.Supervisor so reference-counted binary heaps are reclaimed immediately upon completion, protecting long-lived GenServers from leaks.

Task.Supervisor.async_nolink(Sup, task_fn)
Conditional GET Validation

Send If-None-Match (ETag) and If-Modified-Since headers with every request. Upstream servers return 304 Not Modified when feeds have no updates, bypassing download and parsing.

{"if-none-match", feed.etag}
Differentiated 403 vs 429

Treat 403 Forbidden as a WAF / security block demanding long quarantine cooldowns (30m+). Treat 429 as temporary rate throttling that respects Retry-After headers.

max(1_800, base * round(:math.pow(2, n)))
Decorrelated Retry Jitter

Avoid synchronized thundering herd retries by introducing randomness into the backoff delay. Desynchronizes multiple workers so they do not collide simultaneously.

Enum.random(0..backoff_delay)
Leaky-Bucket Staggering

Schedule feed dispatches sequentially with a minimum inter-request delay (e.g. 2,000ms) rather than firing a burst across all feeds at once.

Process.send_after(self(), :tick, @min_stagger_ms)
Success Reset Boundary

Upon receiving a valid 200 OK or 304 Not Modified, immediately clear consecutive error counters and reset backoff_until to nil in the database state.

%{consecutive_errors: 0, backoff_until: nil}

Checklist: Auditing an External Data Source

  • [ ] Isolation: Is parsing done in an ephemeral process or will large binaries stay pinned in GenServer state?
  • [ ] Conditionals: Are ETags / Last-Modified timestamps tracked and sent on subsequent requests?
  • [ ] WAF Handling: Does a 403 trigger quarantine backoff or rapid aggressive retries that risk IP bans?
  • [ ] Jitter: Is retry delay randomized to prevent synchronized thundering retries?
  • [ ] Rate Smoothing: Are requests staggered with a rate limiter or minimum delay?
