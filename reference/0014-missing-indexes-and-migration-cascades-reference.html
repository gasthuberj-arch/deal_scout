Core Database & Migration Invariants

SQLite Partial Indexes

Index only rows matching a predicate (e.g. non-null sparse flags). Saves 90%+ disk space and keeps index hot in cache while turning table scans into fast index seeks.

create index(:deals, [:country], where: "country IS NOT NULL")
Column-Scoped Triggers

Unscoped AFTER UPDATE ON triggers fire on updates to ANY column. Always scope to the exact modified columns to avoid triggering expensive index rebuilds on unrelated writes.

CREATE TRIGGER deals_au AFTER UPDATE OF title, clean_text ON deals BEGIN ... END;
Bulk Mutation Migration Order

Never run bulk UPDATE/DELETE while FTS triggers are active. Always DROP triggers first, perform data transformations, and rebuild FTS in a single bulk linear pass.

DROP TRIGGER IF EXISTS deals_au; UPDATE deals SET desc = NULL; INSERT INTO deals_fts(deals_fts) VALUES('rebuild');
External-Content FTS5 (`content=`)

Standard FTS5 duplicates all raw text in shadow tables. External-content FTS5 stores only token inverted indexes and references the parent rowid, cutting storage by >60%.

CREATE VIRTUAL TABLE deals_fts USING fts5( title, clean_text, content='deals', content_rowid='id' );
The `OR` Disjunction Trap

Conditions like `col_a >= X OR col_b >= X` prevent standard single B-tree index usage, forcing full-table scans. Normalize schema or query separate indexed paths.

# AVOID: where: d.published_at >= ^t or d.inserted_at >= ^t # PREFER: where: d.published_at >= ^t
Seeded Migration Test Gate

Run migrations up to N-1, seed 1,000 realistic records, execute latest migration N, and assert strict elapsed time (<2s) and WAL log size budgets to catch trigger cascades in CI.

{time, _} = :timer.tc(fn -> Migrator.up(...) end) assert time < 2_000_000
