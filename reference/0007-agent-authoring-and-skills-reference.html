The Two Budgets

Context Load

The cost of always-loaded tokens in the agent's context window. Spends attention on every single turn whether used or not (e.g. AGENTS.md lines, model-invoked descriptions).

Cognitive Load

The mental burden on the human to remember which slash commands and documents exist and when to invoke each. Spend it only where human judgement genuinely matters.

Model-Invoked vs. User-Invoked Skills

Dimension Model-Invoked User-Invoked
Frontmatter Standard (includes description) disable-model-invocation: true
Context Load Continuous (description always in context) Zero (invisible to model until typed)
Reach Autonomous by agent or peer skills Explicit human trigger (e.g. /teach)

Core Writing Levers

  • Leading Words: Use words already rich in model priors (tight, red, tracer bullet, relentless) to collapse multiple paragraphs of explanation into a single hook.
  • Prompt the Positive: Steering by prohibition ("do not write long functions") drags the forbidden concept into context. State the positive target behavior instead ("write compact functions under 20 lines").
  • Progressive Disclosure: Keep top-level steps lean; push detailed edge cases, reference tables, and checklists into disclosed sibling files reached by pointers.
  • Checkable Completion Criteria: Avoid fuzzy bounds like "ensure clean design". Use checkable bounds: "every modified struct has a corresponding test asserting observable output".
