SQLite Indexing & ETS Refresh Reference

Quick reference for avoiding unindexed OR scans, indexing sparse columns, and refreshing ETS caches in-place.

Core Query & Cache Patterns

Single-Column Range Predicate

Avoid indexed_col >= X OR unindexed_col >= X. Normalize data at ingestion so queries filter solely on the indexed column.

where: d.published_at >= ^since_24h
Sparse Partial Index

Index only rows where a sparse nullable column is populated. Keeps B-tree size minimal while making IS NOT NULL counts instant.

index(:deals, [:country], where: "country IS NOT NULL")
In-Place ETS Refresh

Recompute and overwrite existing ETS keys via :ets.insert/2 instead of deleting them first, eliminating cold-cache misses for readers.

StreamCache.refresh(opts, &fetch_deals_from_db/1)
Multi-Representation Key Matching

When refreshing or invalidating by feed, match all representations callers can pass: "all", integer ID, string ID, and slug.

["all", feed_id, to_string(feed_id), feed_slug]
Synchronous Boot Snapshot Seeding

When warming a cache asynchronously in handle_continue/2, seed a safe initial value in init/1 to prevent boot-time stampedes.

seed_empty_snapshot_if_needed()
Scoped 30d vs. Lifetime Metrics

When retention is 365 days, explicitly scope 30-day dashboard joins with d.published_at >= ^since_30d rather than counting all rows.

on: d.feed_id == f.id and d.published_at >= ^since_30d

Query & ETS Audit Checklist

  • [ ] No Unindexed ORs: Does `EXPLAIN QUERY PLAN` confirm every `WHERE` clause uses an index rather than `SCAN deals`?
  • [ ] Partial Indexes Match Queries: Do queries use `fragment("? IS NOT NULL", d.col)` matching the partial index `WHERE col IS NOT NULL`?
  • [ ] Zero Cold Evictions: Are hot caches refreshed in-place by background writers rather than deleted on every write?
  • [ ] Complete Key Coverage: Does cache refresh cover integer IDs, stringified IDs, slugs, and `"all"`?
