Core Engineering Patterns

Percolation Search

Inverting the search direction: matching 1 streaming document against $N$ standing user queries. Solved via Aho-Corasick multi-pattern token scanning and inverted token-to-rule maps in memory.

:binary.compile_pattern(tokens)
Composite Stream Indexing

Combining the filter column(s) with the exact ORDER BY columns in a B-Tree index. Eliminates all database temporary sort files and enables instant forward/backward leaf traversal.

create index(:deals, [:canonical_id, :published_at, :id])
LiveView Dual-Mount Guard

Preventing duplicate SQL queries caused by the static HTTP render and subsequent WebSocket connected mount. Initialize empty streams in mount/3 and defer queries to handle_params/3.

socket |> stream(:items, [])
Proactive Cache Warming

Mitigating the thundering herd / cache stampede. Instead of reactive cache-aside on reader miss, an active GenServer calculates and writes to ETS in the background before expiration.

GenServer.send_after(self(), :warm, interval)
Assoc Preload Safeguard

Avoiding redundant N+1 queries during batch ingestion. Verify if associations are already attached before executing unconditional Repo.preload calls on collections.

Enum.any?(deals, &(not Ecto.assoc_loaded?(&1.feed)))
Strict Filter Null Semantics

Defending against missing or nil attributes in alert predicates. Explicitly reject nil values when evaluating threshold bounds so users are never alerted on garbage data.

not is_nil(deal.price) and deal.price <= rule.max_price

Checklist: Auditing a New Data Feature

  • [ ] Query Plan Check: Run EXPLAIN ANALYZE on feeds and verify index scans without "Sort Method: external merge / quicksort".
  • [ ] LiveView Mount Check: Verify no heavy Ecto queries run inside mount/3 before connected?(socket) or before handle_params/3.
  • [ ] Batch Preload Check: Avoid re-preloading already loaded Ecto associations in high-frequency pipelines.
  • [ ] Stampede Defense: If a query takes > 50ms and is executed by public visitors, use a background GenServer cache warmer.
