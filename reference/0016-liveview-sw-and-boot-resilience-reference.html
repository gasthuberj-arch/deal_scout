Core Browser & OTP Resilience Patterns

Preventing Sticky LongPoll Poisoning

Omit aggressive longPollFallbackMs and clear phx:fallback:LongPoll from sessionStorage so deploy restarts don't trap tabs on HTTP polling.

sessionStorage.removeItem("phx:fallback:LongPoll")
Service Worker Transport Bypass

Never intercept non-GET requests or Phoenix real-time endpoints (/live, /socket, /phoenix) inside a Service Worker.

if (req.method !== 'GET' || url.pathname.startsWith('/live')) return;
Network-First Asset Bundles

Use network-first with cache fallback for /assets/ so deployed CSS and JS updates take effect immediately without stale cache traps.

fetch(request).catch(() => caches.match(request))
Cross-Session Link Semantics

Use href={...} instead of navigate={...} when linking between different router live_session blocks to avoid failed WebSocket hops.

<.link href={~p"/alerts"}>My Alerts</.link>
Asynchronous GenServer Boot

Defer heavy disk I/O or network scans in init/1 to handle_continue/2 so DealScoutWeb.Endpoint binds port 8080 immediately.

{:ok, state, {:continue, :initial_scan}}
Stat-Cached File Hashing

Cache {size, mtime, sha256} in memory when polling replica directories so unchanged WAL files are never re-read and re-hashed.

when prev_size == stat.size and prev_mtime == mtime_iso

Frontend & Deployment Audit Checklist

  • [ ] WebSocket Recovery: Does a tab automatically reconnect over WebSocket after a server restart without getting stuck in LongPoll?
  • [ ] SW Pass-Through: Does `sw.js` ignore all `POST` requests and all `/live`, `/socket`, and cross-origin URLs?
  • [ ] `live_session` Alignment: Do `<.link navigate={...}>` calls stay strictly inside the same `live_session` boundary?
  • [ ] Instant Port Binding: Do all GenServers started before `Endpoint` return from `init/1` in <5ms?
