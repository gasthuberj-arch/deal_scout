Core Distributed Primitives

Postgres Session Advisory Locks

Distributed mutex backed by Postgres. Non-blocking (pg_try_advisory_lock). Automatically freed by the database if the holding node drops its TCP connection.

SELECT pg_try_advisory_lock(1001);
BEAM Global Registration

Register a singleton process across the entire BEAM cluster using {:global, Name}. Only one instance runs cluster-wide; survivors restart it on failure.

GenServer.start_link(M, opts, name: {:global, Name})
Consistent Hash Partitioning

Distribute feed polling across N cluster nodes using :erlang.phash2(feed_id, total_nodes). Each node processes its slice without central coordination bottlenecks.

rem(:erlang.phash2(feed.id), num_nodes) == node_idx
Process Groups (:pg)

Erlang/OTP 23+ native distributed process membership. Allows nodes to discover peer pollers and publish synchronization broadcasts without central brokers.

:pg.join(:pollers, self())
Split-Brain Mitigation

When networks partition, BEAM clusters can form two independent sub-clusters. Using the relational database as the lock arbiter ensures exactly one writer.

Postgres advisory lock / lease fence
Dynamic Rebalancing

When a node joins or leaves, Node.monitor/2 triggers partition recalculation. Only 1/N of the hash keys migrate between surviving members.

:net_kernel.monitor_nodes(true)

Multi-Node Audit Checklist

  • [ ] Duplicate Protection: Are background pollers prevented from running identically on all nodes?
  • [ ] Crash Safety: Does a killed node immediately release its lock without waiting for a 10-minute lease?
  • [ ] Throughput: If running 5+ nodes, is work partitioned across nodes rather than pinned to 1 singleton?
  • [ ] Netsplit Defense: Can two separate network partitions ever poll the same external source at once?
